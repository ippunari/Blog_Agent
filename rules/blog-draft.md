# blog-draft (초안 작성)

> v1.1 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md) (특히 3장 필자, 4장 문체)

## 목적
설계안대로 섹션별 초안을 쓰고, 모든 사실 문장에 출처를 연결해 둔다.

## 입력
- 설계안 + 조사 노트 + 대표 한마디(있으면) + 공통 규칙

## 출력
- `drafts/<slug>.md` → blog-factcheck로
- 파일 머리말: 글 종류 / 필자 / 메인·서브 키워드 / 주·보조 CTA

## 사람 확인 지점
- 없음

## 규칙
- 섹션 단위로 순서대로 쓴다
- **조사 노트에 없는 사실은 쓰지 않는다.** 필요하면 blog-research로 되돌린다
- 필자 목소리(ひかりちゃん)와 글 종류별 도입부(common.md 2장)를 지킨다
- 분량은 blog-outline의 범위 안에서

### 문장 표시 (내부용)
| 표시 | 뜻 |
|---|---|
| `[S3]` | 사실 문장, 조사 노트 S3에 근거 |
| `[OP]` | 대표 한마디 인용 (있을 때만) |
| `[EXP]` | 직접 써 본 결과 (조사 노트의 실습 기록) |
| `[?]` | 출처 없는 사실 문장 (blog-factcheck에서 반드시 처리) |

- 발행할 때 `[S번호]`는 각주 `[1][2]`로 바꾸고 나머지 표시는 지운다

### 대표 한마디
- 있으면 「代表ヤンのひとこと」 상자로. 뜻을 그대로 살려 일본어로 옮긴다. 한국어 원문은 노트에 보존
- 없으면 대표의 의견·경험을 쓰지 않는다. ひかりちゃん의 「써 봤어요」는 실습 기록이 있을 때만 (철칙 1)
