# blog-publish (발행)

> v1.4 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
이미지를 준비하고, 사람의 최종 확인을 받아 Ghost에 발행·예약한다.

## 입력
- 완성 원고 + 메타 정보

## 출력
- Ghost 게시글(초안 → 예약/발행), 시트의 발행 기록 → blog-distribute로

## 사람 확인 지점
- ◆ 미리보기 최종 확인

## 규칙
- **초안 표시 변환** (blog-draft에서 넘어온 것): `[S번호]` → 각주 `[1][2]`(SOURCES 순서), `[EXP]`·`[OP]`·`[?]`·`<!-- 라벨 -->`·`<!-- 차별 N -->` 주석은 지운다(라벨은 디자인용 작은 글씨로), `:::` 상자 → Ghost 카드. 「초안 메모」 절은 발행하지 않는다 (D46, D47)

### 이미지
- 대표 이미지 1200×630, ヒカリちゃん 일러스트 톤 통일
- WebP 200KB 이하, 파일명은 내용을 설명하는 영어, alt는 내용 설명
- 도표는 직접 만들고 데이터 출처 표기
- AI 생성 이미지: 실존 인물·타사 로고 금지
- 스크린샷·외부 이미지는 권리 확인

### Ghost 설정
- 필자: Ghost 스태프 계정 ヒカリちゃん 1개 (D38)
- 기본 태그 = 주제 축(AI·보안·개발), 보조 태그 = 글 종류
- 공개 범위: 전체 공개
- ⚠ **글 발행 때 이메일 자동 발송은 끈다** (뉴스레터는 주 1회 따로)
- FAQ 구조화 데이터는 글마다 코드 삽입
- 에이전트 권한은 초안 작성부터 (common.md 7장)

### 미리보기 확인 (사람)
- 제목·첫 문단 / CTA 링크 작동 / 이미지 / 휴대폰 화면 / SOURCES 링크

### 발행 시간
- 속보: 확인 즉시. 발행 직전에 마감(원래 공표일 + 72시간)을 다시 본다 — 지났으면 속보로 발행하지 않고 깊이 있는 글(교훈 글)로 돌려 설계부터 다시 한다 (D34)
- 일반 글: **평일 오전 8시(JST) 예약**
- 하루 게시 상한을 둔다 (오작동 대비)

### 발행 후
- 기존 관련 글 2개 이상에 새 글 링크 추가 — 설계안 `outlines/<slug>.md` 「역링크」 표대로 (D45)
  - 넣기 직전에 `check_outline.py outlines/<slug>.md --verify-links`로 다시 확인한다 (설계 뒤에 기존 글의 소제목이 바뀌었을 수 있다). 없어진 H2는 그 글의 비슷한 위치를 사람에게 묻는다
  - Ghost 연동 전(임시 방식)에는 「기존 글 URL / H2 / 넣을 문장·앵커」를 파일로 만들어 사람이 붙인다
- Search Console에 색인 요청
- 시트에 발행 기록
- 주제 카드에 `published_at`·`url`을 적고 `status: 발행 완료` → `briefs/done/YYYY-MM/`로 옮긴다. 같은 slug의 research·outlines·drafts·factcheck도 각 폴더의 `done/YYYY-MM/`로 (D40, D44)
