# blog-newsletter (주간 뉴스레터)

> v1.1 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
한 주의 글을 모아 구독자에게 보내 재방문과 상담으로 잇는다.

## 입력
- 이번 주 발행 글, SNS 포인트, 대표 한마디(있으면)

## 출력
- Ghost 뉴스레터 (매주 금요일 오전 8시 JST)

## 사람 확인 지점
- ◆ 테스트 발송을 확인한 뒤 발송

## 규칙

### 구성
1. ひかりちゃん 인사 1~2줄
2. 이번 주 글 (주 30편이므로 깊이 있는 글 위주로 5~8편 골라 각 2~3줄 요약 + 링크, 나머지는 목록)
3. 「今週のヤンのひとこと」 — 이번 주 대표 한마디가 있을 때만 (없으면 이 칸을 빼고 ひかりちゃん 「今週の編集部メモ」)
4. 다음 주 예고
5. CTA 1개

### 제목
- 전각 30자 이내, 이번 주 가장 강한 수치나 질문 하나

### 링크
- UTM: `?utm_source=newsletter&utm_medium=email&utm_campaign={YYYY-Www}`

### 법률 (特定電子メール法 등)
- 구독 동의 (가입 확인 메일)
- 발신자 정보 표시
- 수신 거부 링크 필수
- ⚠ 대표 + 기술 보안팀 확인 항목

### 발송
- 테스트 발송 → 사람 확인 → 발송
