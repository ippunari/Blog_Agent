# blog-factcheck (사실 대조)

> v1 2026-11-19 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
초안의 사실을 하나씩 원문과 대조해 틀린 내용과 근거 없는 내용을 없앤다.

## 입력
- `drafts/<slug>.md`, 조사 노트

## 출력
- 수정된 초안 + SOURCES 목록 → blog-polish로
- `factcheck/<slug>.md` 대조 보고서

## 사람 확인 지점
- 없음 (통과 기준을 못 넘으면 사람에게 알린다)

## 규칙
- 대조 대상: 수치·날짜·고유명사·인용
- 하나씩 원문(조사 노트의 원어 문장, 필요하면 URL 재확인)과 대조 → **일치 / 불일치 / 확인 불가**
- `[?]` 출처 없는 사실 문장: 출처 추가 / 의견 표현으로 변경 / 삭제 중 하나
- **실명 기업 문장**: 공식 발표의 표현 범위를 넘지 않는지 확인 (명예훼손 방지)
- **속보**: 발행 직전에 공식 발표가 바뀌지 않았는지 다시 확인
- blog-polish에서 바뀐 사실 문장은 다시 대조

### 통과 기준
- 불일치 0개
- 출처 없는 사실 0개
- 확인 불가인 내용은 글에서 뺀다

### SOURCES 형식
번호 / 제목 / 발행처 / 발표일 / URL / 확인일 (원문 언어 표기)
