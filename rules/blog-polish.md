# blog-polish (다듬기)

> v1.1 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md) (특히 4장 문체, 6장 SEO·AEO·AIO)

## 목적
문장과 톤을 다듬고, SEO·AEO·AIO 규칙을 점검하고, 메타 정보를 쓴다.

## 입력
- 사실 대조를 통과한 초안

## 출력
- 완성 원고 + 메타 정보 + 체크리스트 결과 → blog-publish로

## 사람 확인 지점
- 없음 (blog-publish 미리보기에서 확인)

## 규칙

### 순서
문장 다듬기 → 바뀐 사실 문장 재대조(blog-factcheck) → 체크리스트 → 메타

### 문장 다듬기
- 금지 표현 검사 (common.md 4장)
- 60자 넘는 문장 나누기
- 같은 어미 3번 연속 금지 (〜です。〜です。〜です。)
- 용어 표기 통일 / 전문 용어 첫 등장 풀이 확인
- 필자 목소리 확인 (ひかりちゃん) / 「써 봤어요」 표현이 실습 기록과 맞는지
- 자동 교정 도구(textlint 일본어 규칙 등) 실행 → 오류 0
- 보이지 않는 특수 문자 제거

### 체크리스트
- common.md 6장(SEO 12항목·AEO·AIO)을 항목별 통과 / 미통과 표로

### 메타 정보
- 검색용 제목 (본문 제목과 달라도 됨)
- 메타 설명 (전각 80~120자, 핵심은 앞 50자)
- SNS 공유용 제목·설명
- 목록용 요약 (excerpt)
- slug
