# blog-research (조사)

> v1 2026-11-19 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
글의 모든 사실에 믿을 수 있는 근거를 붙이고, 일본어 경쟁 글에 없는 차별 포인트를 찾는다.

## 입력
- 선택된 주제·키워드, 대표 코멘트, 후보의 출처 링크

## 출력
- `research/<slug>.md` 조사 노트 → blog-outline으로

## 사람 확인 지점
- ◆ 사용법 글: 사람이 직접 써 보고 화면을 캡처한다 (에이전트는 체크리스트 제공)

## 규칙

### 근거 기준
- 주장마다 A등급 출처 1개 이상
- 수치·날짜·인용은 A 또는 B등급만
- C등급은 단서로만

### 1차 출처 찾는 순서
기사 속 원문 링크 → 공식 뉴스룸·블로그·문서 → 정부·기관 → 공식 논문·저장소

### 원문 다루기
- 원문 문장은 **조사 노트에만** 원어 그대로 기록 + 일본어 번역 메모 (사실 대조의 증거)
- 본문은 원문을 바탕으로 새로 쓴다. 원문 전재·번역 전재 금지 (common.md 5장)
- 발언 자체가 중요한 경우만 1~2문장 짧은 인용 후보로 표시

### 범위
- **일반 글**: 일본 국내 통계·자료 보충 / 일본어 검색 상위 글 3~5개를 읽고 빠진 내용을 "차별 포인트"로 기록 / 상위 10개 글 유형(가이드/목록/뉴스) 기록
- **속보**: 1차 출처 + 일본에 미치는 영향만. 30분 이내

### 직접 써 보기 (사용법 글)
- 에이전트가 체크리스트 생성: 가입 절차, 요금, 일본어 지원, 상업적 이용 가능 여부, 찍어야 할 화면 목록
- 캡처 속 개인정보는 가린다

### 확인일
- 모든 사실에 확인한 날짜를 적는다 (AI 요금·기능은 자주 바뀜)

### 조사 노트 형식 (`research/<slug>.md`)
```
## 핵심 사실
| ID | 사실(일본어) | 원문 문장(원어) | 출처명 | URL | 등급 | 발표일 | 확인일 |
| S1 | ... |

## 수치표
## 일본어 경쟁 글 분석 (상위 3~5개, 글 유형, 빠진 내용 = 차별 포인트)
## 짧은 인용 후보
## 아직 확인하지 못한 사항
## 직접 써 본 결과 (사용법 글)
```
