# blog-perspective (대표 코멘트)

> v1 2026-11-19 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
다른 곳에 없는 경험과 의견을 설계 전에 확보한다. 대표 부담은 글 1편당 5분 이내.

## 입력
- blog-topic에서 선택된 주제·글 종류

## 출력
- 대표 답변(한국어 원문) + 일본어 정리 + 훅·첫 문장 후보 → blog-research, blog-outline으로

## 사람 확인 지점
- ◆ 대표가 Google Sheets의 "대표 코멘트" 칸에 **한국어로** 3~5줄 답한다

## 규칙

### 절차
주제 확정 → 에이전트가 질문 3개 생성 → 대표가 시트에 답 → 에이전트가 일본어로 옮기고 훅·첫 문장 후보로 정리

### 글 종류별 질문
| 글 종류 | 질문 |
|---|---|
| AI 속보 | 처음 든 생각 / 일본 중소기업에 영향이 있나·왜 / 독자에게 한마디 |
| AI 사용법 | 써 봤나·좋았던 점·불편한 점 / 업무에 쓴다면 어디에 |
| AI 업무 활용·도입 가이드 | 비슷한 상담·현장 사례 / 흔한 실수 / 비용·기간 감각 |
| 보안 사고 해설 | 고객사에서 비슷한 일이 있었나 / 오늘 당장 확인할 것 1가지 |
| 보안 대책 가이드 | 실제로 어디서 막히나 / 무엇부터 해야 하나 |
| 개발 발주·견적 | 경험담 / 실패 사례 / 발주 전에 꼭 할 것 |

### 반드시 지킬 것
- **대표의 경험·의견을 지어내지 않는다.** 답이 없으면 1인칭 경험 표현 없이 쓴다
- 한국어 답을 일본어로 옮길 때 뜻을 바꾸거나 부풀리지 않는다. 한국어 원문은 노트에 보존
- 고객 사례는 업종·규모만. 회사명·특정 가능한 정보 금지
- 고객·내부 정보는 시트에도 쓰지 않도록 안내한다

### 무응답 처리
- 속보: 3시간 안에 답이 없으면 코멘트 없이 진행
- 일반 글: 답을 기다린다
