# blog-topic (주제 선정)

> v1.2 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
후보마다 검색어를 찾고 점수를 매겨, 속보 2편·일반 글 2편(주당)을 사람이 고르게 한다.

## 입력
- blog-collect의 후보 목록
- blog-measure의 점수 기준 조정 결과 (승인된 것만)

## 출력
- Google Sheets에 상위 후보 (회사 공유 드라이브 「Atatakai Digital」 › `03_Blog/topics`에 새 시트로 올림) + `topics/YYYY-MM-DD-am|pm.md` 상세 기록
- 선택된 주제마다 `briefs/<slug>.md` 주제 카드
- 선택된 주제: 글 종류, 메인 키워드 1 + 질문형 서브 키워드 3~5, 가제목 → blog-perspective로

## 사람 확인 지점
- ◆ 시트에서 "선택" 체크로 주제와 가제목을 고른다 (대표·팀원)

## 규칙

### 주제 축
- **AI**: 중소기업 업무에 쓰는 AI / 일본 중소기업에 영향이 있는 해외 AI 뉴스 / 업무와 이어지는 도구 사용법
- **보안**: 중소기업 홈페이지·메일·PHP·WordPress / 일본 기업 보안 사고 해설(교훈 중심)
- **개발**: 발주·견적·MVP·IT 담당자가 없는 회사

### 쓰지 않을 주제
- 루머·미확인 정보만 제외
- 엔터·창작 AI, 투자·실적 뉴스, 개발자 심층 기술은 허용 — 점수가 낮아 자연히 후순위. 쓸 때는 "중소기업에 무슨 의미인가"로 풀어 쓴다

### 후보 만들기
- candidates의 후보(C번호)에 더해, **질문 입구의 질문·검색어를 같은 뜻끼리 묶어 일반 글 후보**를 만든다 (뉴스가 없는 축, 특히 개발을 채운다)
- 점수는 2단계: ① 검색 없이 1차 점수 → 속보 AI 몫 상위 5개, 속보 보안·개발 몫 상위 8개, 일반 상위 8개 ② 이것만 검색어·일본어 상위 결과를 조사해 최종 점수
- 상위 후보는 표마다 **5개**를 사람에게 보여 준다 (속보 AI / 속보 보안·개발 / 일반)

### 검색어 찾기
- 후보마다 독자가 실제 검색하는 일본어 메인 키워드 1개
- 질문형 서브 키워드 3~5개 (자동완성·「他の人はこちらも質問」·知恵袋). 질문형 = 질문 의도가 있는 검색어(〜とは·確認方法·対策·違い·費用 등)도 포함
- 실제로 확인한 검색어만 쓴다. 근거가 약하면 「추정」 표시

### 점수표 (전환 연결성 최우선)
| 기준 | 비중 | 1~5점 판단 |
|---|---|---|
| 전환 연결성 | 35% | AI 도입 가이드·보안 대책·개발 발주 = 5 / 보안 사고 해설 = 4 / 업무 활용 = 3 / 사용법 = 2 / 속보 = 1 |
| 일본어 자료 부족 | 20% | 일본어 검색 상위에 쓸 만한 글이 없으면 5 |
| 검색 수요 | 20% | 자동완성·Q&A에 반복 등장하면 높게. 속보는 관심이 오르는 중인지로 |
| 회사 경험 | 15% | 대표·회사가 직접 해 본 분야면 5 (분야별 값: `.claude/skills/blog-topic/experience.json`, ⚠ 잠정 — 대표 확인 필요) |
| 수명 | 10% | 1년 이상 유효 5 / 1주 안에 묻히면 1 |

### 속보 / 일반 판정
- **속보**: 발표 72시간 이내 + 관심 상승 중
- **일반 글**: 질문형 검색어가 있고 6개월 이상 유효
- 속보와 일반은 **따로 순위**를 매겨 각각 주 2편 선정
- **속보 2편 중 1편은 AI**: 속보는 「AI」(주제 축 AI)와 「보안·개발」로 순위를 나누고 각 1편을 고른다. 72시간 안 AI 후보가 없으면 보안·개발에서 2편 (D28)
- 「발표」는 **원래 공표일**이다. 주간 보고·취약점 목록에 다시 실린 날이 아니다 (JPCERT Weekly Report, CISA KEV 등)
- 총점 = 가중합 ÷ 5 (100점 만점). 동점이면 자료부족 → 일본어 보도 없음 → 최근 발표 순

### 1키워드 1글
- 메인 키워드가 기존 글과 겹치면 새 글 대신 기존 글 업데이트를 제안한다

### 시트 칸 구성 (Google Sheets 연동 시)
- 시트 1개, 첫 칸 「구분」(속보 AI / 속보 보안·개발 / 일반)으로 나눈다 (rules/common.md 7장 D: 회사 계정끼리만 공유)
- 사람은 「선택」 칸 드롭다운에서 ○를 고르고 「선택자」에 이름을 적는다. 가제목은 시트에서 고쳐도 된다
- 칸 순서: 구분 / 선택 / 순위 / ID / 가제목 / 글 종류 / 메인 키워드 / 총점 / 마감 / 1키워드1글 / 서브 키워드 / 점수 5개(전환·자료부족·수요·경험·수명) / 원문 URL / 상세 파일 / 선택자 / 메모
- 구분 다음 9칸은 `topics/` 파일의 순위표와 같다. `topics/` 파일은 상세 기록으로 남는다
- blog-perspective 단계에서 「대표 질문」「대표 코멘트」 칸을 오른쪽에 더한다

### 발행 리듬
- 주 4편(속보 2 + 일반 2) + 뉴스레터 1회
