# blog-measure (측정과 개선)

> v1 2026-11-19 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
무엇이 노출·방문·구독·문의로 이어졌는지 보고, 다음 주제 선정과 기존 글 개선에 반영한다.

## 입력
- Search Console, GA4(UTM), Ghost(구독·오픈율), 문의 기록

## 출력
- `reports/YYYY-Www.md` 주간 리포트 (월요일 아침)
- 월간 개선 제안

## 사람 확인 지점
- ◆ 점수 기준 조정·글 개선안은 사람이 승인한 뒤 반영

## 규칙

### 주간 리포트 (월요일 아침)
- 글별 검색 노출·클릭·순위 (Search Console)
- 플랫폼별 방문 (GA4, UTM)
- 구독자 증감·오픈율 (Ghost)
- 문의 수와 거쳐 온 글

### 월간 개선 제안
- 노출 많고 클릭 적은 글 → 제목·메타 설명 개선
- 순위 8~20위 글 → 내용 보강
- 주제 점수표 비중 조정안 → 승인 후 blog-topic에 반영

### 목표
- 3개월 목표: 한 달 운영 후 데이터를 보고 정한다

### 선행 조건
- Search Console·GA4 설치, Ghost 회원 통계 확인
