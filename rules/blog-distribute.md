# blog-distribute (SNS 배포)

> v1.1 2026-11-20 · 운영하며 보강 · 공통 규칙: [common.md](common.md)

## 목적
발행한 글을 5개 플랫폼에 맞게 다시 써서 블로그로 사람을 데려온다.

## 입력
- 발행된 글, 설계안의 SNS 포인트(수치·의견·질문), 대표 이미지

## 출력
- 플랫폼별 게시글 5개 (UTM 링크 포함)

## 사람 확인 지점
- ◆ 확인한 뒤 게시

## 규칙

### 공통
- 플랫폼마다 새로 쓴다 (복사 금지)
- SNS 포인트(수치·의견·질문)를 쓴다
- UTM: `?utm_source={x|threads|note|linkedin|facebook}&utm_medium=social&utm_campaign={slug}`
- 게시 시간: 블로그 발행과 같은 시간 (일반 글 오전 8시, 속보는 발행 직후)
- 처음부터 5곳 모두 운영

### 계정
- 기본: 회사 계정
- LinkedIn: 회사 페이지 + 편집부 담당자 개인 계정 (대표 개인 계정은 선택 — 나중에 추가)
- Facebook: 회사 페이지 + 편집부 담당자 개인 계정에서 공유 (대표 개인 계정은 선택)
- 개인 계정 게시도 사람이 확인하고 올린다 (철칙 2). 파일에 개인 이름·계정 ID를 적지 않는다

### 플랫폼별
| 플랫폼 | 길이 | 규칙 |
|---|---|---|
| X | 전각 140자 이내 | 핵심 수치나 질문으로 시작 / **링크는 답글에** / 해시태그 1~2 / 대표 이미지 첨부 |
| Threads | 500자 이내 | ひかりちゃん 목소리의 대화체 / 링크 1개 |
| note | 1,000~2,000자 | 요약판 + 「全文はブログで」 링크 / **전문 전재 금지** / 해시태그 3~5 |
| LinkedIn | 300~600자 | 회사 관점(글의 핵심 판단·수치), 대표 한마디가 있으면 앞에 / 링크는 첫 댓글 |
| Facebook | 200~400자 | 링크 미리보기 / 중소기업 사장층 대상 |

### 보안
- 모든 계정 2단계 인증, 예약·초안 기능부터 사용 (common.md 7장)
